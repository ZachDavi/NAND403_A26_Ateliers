Description de l’outil

Cet outil facilite deux opérations très courantes dans Maya : le Freeze Transformations (figer les transformations) et le Delete History. Comme ces deux actions vont souvent de pair, l’outil centre également le pivot de chaque objet sélectionné en son centre.

Installation de l’outil

-Ouvrir la version de Maya de votre choix.
-Aller dans le menu Windows -> General Editors -> Script Editor.
-Cliquer sur l’engrenage à gauche de la barre des shelves (l’endroit où se trouvent vos outils).
-Cliquer sur New Shelf et lui donner un nom.
-Ouvrir le fichier « Center_&_Delete.py » et copier le code qu’il contient.
-Dans le Script Editor, sélectionner l’onglet Python (par défaut, c’est MEL).
-Coller le code dans l’éditeur, puis appuyer sur CTRL+A pour tout sélectionner.
-Maintenir le clic molette sur le texte sélectionné et le glisser vers votre nouveau shelf.
-Une icône devrait alors apparaître.

Changer l’icône de l’outil

-Faire un clic droit sur l’icône, puis choisir Edit.
-Aller dans l’onglet Shelves.
-Cliquer sur l’icône de dossier à côté du champ Icon Name.
-Sélectionner le fichier inclus dans le dossier de l’outil, nommé « icone_multidelete_outil ».
-Cliquer sur Save All Shelves.
